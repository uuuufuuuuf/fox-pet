# 여우귀 친구 🦊

바탕화면 작업 표시줄 위에서 지내는 여우귀 캐릭터 "여유노"를 키우는 Windows 데스크톱 펫이에요.

## 기능

- 작업 표시줄 위를 걸어 다니고, 옆 모니터로도 건너가요.
- 오른쪽 클릭 메뉴에서 밥 주기, 놀아 주기, 재우기를 할 수 있어요. 각각 전용 모션이 있어요.
- 클릭하면 쓰다듬기, 끌어서 놓으면 떨어져요. 높이 떨어뜨리면 철퍼덕 엎어져요.
- 포만감, 기분, 친밀도, 외로움에 따라 대사와 행동이 달라져요.
- 가끔 "나 좋아해…?" 하고 물어보고, 대답에 따라 반응해요.
- 하루에 한 장씩 여유노의 일기를 써요.

## 저장되는 파일

투명하게 알려 드려요. 이 앱은 아래 두 곳에만 파일을 써요.

| 위치 | 내용 |
|---|---|
| `%APPDATA%\fox-pet\pet.json` | 펫 상태 (포만감, 기분, 친밀도, 창 위치 등) |
| `C:\여유노\YYYY-MM-DD_여유노일기.txt` | 여유노의 하루 일기 (숨김 폴더). 3일 지난 일기는 자동으로 지워져요. 메뉴의 "📔 일기 보기"로 열 수 있어요. |

일기에는 **이 앱 안에서 있었던 일만** 적혀요. 밥이나 놀기 횟수, 같이 있던 시간, 질문에 한 대답 같은 것들이에요. 다른 프로그램 사용 기록, 키보드 입력, 화면, 파일, 인터넷 활동은 읽거나 저장하지 않아요. 네트워크 통신도 하지 않아요.

## 설치

[Releases](../../releases)에서 `FoxPet-Setup-*.exe`를 받아 실행하세요.

## 직접 빌드하기

Node.js 20 이상이 필요해요.

```bash
npm ci
npm start          # 실행
npm run dist       # 설치 파일 만들기 (dist 폴더)
```
